# Breast Cancer Classifier

[Breast cancer is the most common cancer among women worldwide.](https://ecancer.org/en/news/27867-breast-cancer-remains-the-most-common-cancer-among-women-worldwide-with-annual-cases-expected-to-reach-over-3-5-million-by-2050) This project uses scikit-learn's RandomForestClassifier and the Wisconsin breast cancer dataset to predict whether breast tumor cells are benign or malignant (after some exploratory data analysis, of course).

I chose to use a random forest model for this project as it was the highest-performing model at baseline for this dataset according to the [UCI repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic). This makes sense as with 300+ samples, using a single decision tree would be so deep the risk of overfitting is high but it's not enough samples for other models like deep neural networks that typically require more data to reduce risk of overfitting. While neural networks have been used on this dataset, their accuracy and precision varies much more than that of random forests at baseline and it tends to be lower overall.
